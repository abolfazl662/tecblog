
## ⚙️ Installation

### 1️⃣ Clone

```bash
git clone https://github.com/abolfazl662/tecblog.git
```

### 2️⃣ Enter the project

```bash
cd tecblog
```

### 3️⃣ Get dependencies

```bash
flutter pub get
```

### 4️⃣ Run

```bash
flutter run
```
